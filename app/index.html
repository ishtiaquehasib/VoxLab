Parity sections — scaffold, not finished features

Statuses are honest: Ready = tested here, Scaffold = code exists but not fully tested, Needs model download = model not downloaded in this task.

Record — Browser mic recorder (needs mic permission; live mic test requires a real browser, not done by this agent)

Record up to 30 seconds from your microphone, watch the live waveform, then upload the clip. System capture is NOT implemented in-app — see /api/parity/capture-info for the OS-specific setup it needs.






Or upload a file instead (WAV/MP3/FLAC/WebM, max 50 MB):

Dictate — faster-whisper via librosa decode (av file-path bug avoided)

Upload audio to transcribe. Returns a real transcript or a clear error, never a fake transcript, if faster-whisper/librosa is unavailable. A global shortcut that pastes into any app is NOT built — dictation here works inside this page only.

MCP agent voice — Kokoro ONNX synthesis for Kokoro preset voices

Per-agent voice mapping, synthesized with Kokoro ONNX when the mapped voice is a Kokoro preset. Parler/Edge/clone voices return synthesized: false with the reason — they need their own engine.

Personalities — Rewrite / Compose — Template only

Template transforms only. A real persona Rewrite/Compose needs Qwen3 LLM, which is not loaded here.

Stories — Scaffold (ffmpeg)

Concatenate WAV files already in output/, comma-separated filenames only. No paths outside output/ are accepted.

Effects — Scaffold (ffmpeg)

Speed 0.5–2.0, volume 0.1–3.0, optional echo, applied to a file already in output/.

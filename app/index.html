Parity sections — scaffold, not finished features

Statuses are honest: Ready = tested here, Scaffold = code exists but not fully tested, Needs model download = model not downloaded in this task.

Record — Browser mic recorder (needs mic permission; live mic test requires a real browser, not done by this agent)

Record up to 30 seconds from your microphone, watch the live waveform, then upload the clip (POST /api/parity/mic-upload, 30 s cap + waveform metadata for WAV). Windows system capture code path exists in backend/parity.py (sounddevice WASAPI loopback) but its live Windows test is pending — see /api/parity/capture-info.






Or upload a file instead (WAV/MP3/FLAC/WebM, max 50 MB):

Dictate — faster-whisper via librosa decode (av file-path bug avoided)

Upload audio to transcribe. Returns a real transcript or a clear error, never a fake transcript, if faster-whisper/librosa is unavailable. Shortcut dictation is wired server-side (POST /api/parity/dictate-shortcut: transcribe + clipboard + optional paste, Ctrl+Alt+V on Windows) — its live Windows hotkey/paste test is pending, so dictation here works inside this page only until that test passes.

MCP agent voice — Kokoro ONNX synthesis for Kokoro preset voices

Per-agent voice mapping, synthesized with Kokoro ONNX when the mapped voice is a Kokoro preset. Parler/Edge/clone voices return synthesized: false with the reason — they need their own engine.

Personalities — Rewrite / Compose — Qwen3-0.6B when loaded, else template (0.6B rewriting is minimal, sometimes verbatim — not strong rewriting)

Presets: neutral, warm narrator, noir detective, news anchor, friendly teacher, calm guide — or any free-form persona name. Response always says llm_used and verbatim.

Stories — Wired to backend (ffmpeg timeline; UI playback not yet tested in a real browser)

Timeline: one track per line, comma-separated: file, start_seconds, trim_start, trim_end, volume — e.g. last.wav,0,0,,1.0. Tracks with a start are mixed in parallel; without a start they play in sequence. Crossfade (ms) applies to sequence mode only. Legacy mode: comma-separated filenames only, concatenated. Files must already be in output/; no paths outside output/ are accepted. Mic recording and system capture live tests are still pending — see Record above.

Auto-chunking — Text only: splits long text at sentence boundaries, synthesizes nothing

Splits at . ! ? … and the Bengali danda (।), grouping sentences into chunks up to max_chars. Each chunk is then synthesized separately and assembled with the story builder (crossfade optional).


Effects — Wired to backend (ffmpeg; reverb is a multi-tap aecho approximation, not convolution/Pedalboard reverb)

Speed 0.5–2.0, volume 0.1–3.0, pitch −12..+12 semitones (duration preserved), lowpass/highpass in Hz, delay 0–2000 ms, optional chorus, compressor, legacy echo. Preview trims the output to the first N seconds using the same chain.

Remote mode — local or a server on your own network (no auth, no encryption — do not expose it publicly)

Mode comes from VOXLAB_REMOTE_MODE / VOXLAB_REMOTE_BASE_URL on the server. Start checks the local server; Health checks the configured base URL.

Transcript refinement — toggle, Qwen3-0.6B when loaded

With refinement on, fillers and self-corrections are cleaned only; meaning, names and facts are preserved. With it off, or if the LLM is unavailable, the original is returned unchanged.

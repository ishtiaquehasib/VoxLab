Clone a voice

Clone only a voice you own or have explicit permission to use. Never clone someone else's voice for a public service. Primary cloning engine: Chatterbox (backend/clone.py); the in-app clone engines below are Chatterbox Turbo, LuxTTS, TADA and Qwen CustomVoice. Reference files must already be in output/ — upload one via Record, or name the Kokoro reference.





Design a voice from a description

Skeleton only: POST /api/parity/voice-design returns needs_download=true until a real generation passes. Qwen VoiceDesign, ~4.54 GB, 10 languages, no Bengali; licence not verified on its HF card, so it is not shipped as verified.



Record

Browser mic recorder (needs mic permission; live mic test requires a real browser). Record up to 30 seconds, watch the live waveform, then upload (POST /api/parity/mic-upload, 30 s cap + waveform metadata for WAV). Windows system capture code path exists in backend/parity.py (sounddevice WASAPI loopback) but its live Windows test is pending — see Settings > Capture info.






Or upload a file instead (WAV/MP3/FLAC/WebM, max 50 MB) — this also serves as Import Voice for cloning:

Dictate

Upload audio to transcribe (faster-whisper via librosa decode). Returns a real transcript or a clear error, never a fake transcript. Shortcut dictation is wired server-side (POST /api/parity/dictate-shortcut: transcribe + clipboard + optional paste, Ctrl+Alt+V on Windows) — its live Windows hotkey/paste test is pending, so dictation here works inside this page only until that test passes.

Personalities — Rewrite / Compose

Presets: neutral, warm narrator, noir detective, news anchor, friendly teacher, calm guide — or any free-form persona name. Response always says llm_used and verbatim. Qwen3-0.6B rewriting is minimal, sometimes verbatim — not strong rewriting.

Transcript refinement

With refinement on, fillers and self-corrections are cleaned only; meaning, names and facts are preserved. With it off, or if the LLM is unavailable, the original is returned unchanged.


Stories

Timeline: one track per line, comma-separated: file, start_seconds, trim_start, trim_end, volume — e.g. last.wav,0,0,,1.0. Tracks with a start are mixed in parallel; without a start they play in sequence. Crossfade (ms) applies to sequence mode only. Legacy mode: comma-separated filenames only, concatenated. Files must already be in output/; no paths outside output/ are accepted. UI playback against a running server was not browser-tested when this panel was wired.

Auto-chunking

Text only: splits long text at sentence boundaries, synthesizes nothing. Splits at . ! ? … and the Bengali danda (।), grouping sentences into chunks up to max_chars. Each chunk is then synthesized separately and assembled with the story builder (crossfade optional).


Effects

Wired to backend (ffmpeg + real convolution reverb; aecho only as labelled fallback). Speed 0.5–2.0, volume 0.1–3.0, pitch −12..+12 semitones (duration preserved), lowpass/highpass in Hz, delay 0–2000 ms, optional chorus, compressor, legacy echo. Preview trims the output to the first N seconds using the same chain. ffmpeg is bundled via imageio-ffmpeg when available, else PATH ffmpeg.





MCP agent voice

Per-agent voice mapping, synthesized with Kokoro ONNX when the mapped voice is a Kokoro preset. Parler/Edge/clone voices return synthesized: false with the reason — they need their own engine. Endpoint: POST /api/mcp/speak.

Remote mode

Local or a server on your own network (no auth, no encryption — do not expose it publicly). Mode comes from VOXLAB_REMOTE_MODE / VOXLAB_REMOTE_BASE_URL on the server. Start checks the local server; Health checks the configured base URL.

Models

Chatterbox Turbo, LuxTTS, TADA, Qwen CustomVoice, Whisper Turbo, Qwen3 LLM — tested in lab (see PARITY.md for exact seconds/bytes/transcripts), not bundled in the installer; each needs its model download on first use. LuxTTS/TADA need luxtts_src/ / tada_src/ — gitignored test copies, not bundled — and honestly return 503 on a fresh install until vendored. Generate with a model from the Clone panel; status here is read-only.

System capture: needs OS setup (see Settings > Capture info). No testimonials, star counts, or download counts are shown anywhere in this app.

Settings — server status

Real status only. Startup status is GET /api/parity/startup-status (added with this redesign; older builds without it fall back to /api/parity/status). It does not claim any model is downloaded.

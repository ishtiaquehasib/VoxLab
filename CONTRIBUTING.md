# Contributing to VoxLab

Thanks for helping make VoxLab better. VoxLab is a free, local-first
voice studio for PC — no account, no cloud, open models only.

## How to contribute
1. Fork the repo, create a branch, make a focused change.
2. Keep the app local-first: no API keys, no paid service, no tracking.
3. Test your change locally: `python backend/server.py`, open
   http://127.0.0.1:8000, generate a sample, play it, download it.
4. Open a pull request with what changed and how you tested it.

## Rules that matter here
- Voice cloning: only clone a voice you own or have explicit permission
  to use. Never add a feature that clones someone else's voice for a
  public service.
- Do not copy another project's code, voices, or assets. Take ideas,
  write your own implementation, and credit the original project.
- Keep Bengali voices open-source only — never ElevenLabs' own voices.
- Keep the app PC-only for v1, and keep the VoxLab logo theme
  (dark navy + cyan-blue-purple) and the "Developed by Ishtiaque Hasib"
  credit intact.

## Reporting a bug
Open an issue with: what you did, what you expected, what happened,
your OS and Python version, and the exact error text if there is one.

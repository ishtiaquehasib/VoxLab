# Security Policy

## Supported versions
VoxLab v1 (PC) is the currently supported version. Older test builds
are not supported.

## Reporting a vulnerability
If you find a security issue in VoxLab, please report it privately
first — do not open a public issue with exploit details.

- Open a private report on GitHub, or contact the maintainer through
  the VoxLab website / GitHub profile.
- Include: what the issue is, where it is, and how to reproduce it
  (without real personal data or real voices you do not own).

We will confirm receipt, fix the issue, and credit you in the release
notes if you wish.

## Scope notes
- VoxLab runs locally on the user's own PC. It sends no audio, text,
  or personal data to any server by design.
- Models are downloaded once from Hugging Face on first run. Check
  each model's own licence and source before use.
- Voice cloning is powerful: only clone voices you own or have
  explicit permission to use.
